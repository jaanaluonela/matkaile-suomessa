MATKAILE SUOMESSA v331 – OULU NÄKYVIIN

Tämä ZIP on päivitys olemassa olevaan GitHub-sivustoon, ei koko sivuston varmuuskopio.

MIKÄ KORJAANTUU?
- Paikkakunnat-sivulla on suora linkki Oulun kattavaan oppaaseen.
- Pohjois-Pohjanmaan sivun alussa on Oulu ja Oulun seutu helposti löydettävissä.
- Myös vanhalla kunnat.html-sivulla on linkit Ouluun.
- Oulun oma sivu sisältää 37 kohdetta ja suodatuksen. Oulun seutu -sivu sisältää alueen muita paikkakuntia.
- Kaikilla sivuilla jatkaa vaalea neljän painikkeen alavalikko: Koti, Paikkakunnat, Pysähdy matkalla, Omat matkat.
- Edellisten pakettien (v329 ja v330) aineisto on mukana samassa paketissa.
- Etusivun sisältöä, muita paikkakuntia tai olemassa olevia suosikkeja ei poisteta.

ASENNUS GITHUBIIN
1. Pura ZIP tietokoneelle. Siirrä KAIKKI ZIP-paketin tiedostot GitHub-repositorion JUUREEN
   vastaaviin hakemistoihin. Muista myös piilotettu .github/workflows-kansio.
   Korvaa samannimiset tiedostot. Älä lataa ZIP-tiedostoa sellaisenaan verkkosivulle.
2. Tallenna muutokset GitHubiin (Commit changes).
3. Tarkista GitHub > Actions > "Oulu löydettäväksi ja sisältösivut v331".
   Työn pitää mennä vihreäksi; tarvittaessa Settings > Actions > General >
   Workflow permissions > Read and write permissions.
4. Jos GitHub Actions ei päivitä HTML-sivuja, aja projektin juuressa:
       python tyokalut/paivita_rakenne_v329.py
       python tyokalut/paivita_rakenne_v330.py
       python tyokalut/paivita_oulun_loydettavyys_v331.py
   ja vie muuttuneet HTML-sivut takaisin GitHubiin.
5. Tarkista osoitteet /maakunnat.html, /pohjois-pohjanmaa.html,
   /oulu.html ja /oulun-seutu.html. Päivitä selaimessa tarvittaessa välimuisti.
