ASENNUS GITHUBIIN
1. Tee ensin GitHub-reposta varmuuskopio: Code > Download ZIP.
2. Pura TAM̈Ä v343 ZIP koneelle.
3. Lataa kaikki sen mukana olevat 7 asennustiedostoa GitHub-repositorioosi
   samoihin polkuihin. Korvaa .github/workflows/alavalikko-v301.yml,
   jos se löytyy entuudestaan. Säilytä kansiorakenne tyokalut/ ja palautus/.
   ÄLÄ pura sisempää palautus/vanha_sisalto_v342.zip -tiedostoa.
4. GitHubissa Commit changes. Automaattinen Actions-työ nimeltä
   "Vanhat kuntatiedot ja erilliset etusivut v343" tekee muutokset.
   Tarvittaessa Actionsin työnkululle tulee antaa Contents: read and write.
5. Odota GitHub Pages -julkaisua. Lataa puhelimella ja tietokoneella
   sivusto uudelleen (välimuisti voi säilyttää vanhan version).
