MATKAILU SUOMESSA v263 – ETUSIVUN JA NÄE JA KOE -SIVUN KORJAUS

Tämä on pieni PÄIVITYS nykyiseen GitHub-sivustoon, ei koko sivusto.

1. Pura ZIP-tiedosto koneella.
2. Avaa GitHubista nykyisen matkaile-suomessa-projektin päätason tiedostot.
3. Lisää ZIP:n sisältämät neljä verkkosivutiedostoa samaan kansioon (projektin juuri).
4. Kun GitHub kysyy korvataanko index.html ja kayntikohteet.html,
   korvaa vain nämä kaksi samannimistä tiedostoa.
5. Hyväksy/Commit changes ja odota GitHub Pagesin päivittymistä.
6. Päivitä sivu tarvittaessa selaimen välimuistin ohittaen.

Päivittyvät:
- index.html (uusin v262 etusivupohja + responsiivinen asettelu)
- kayntikohteet.html (maakunta- ja kuntavalikot sekä responsiivinen asettelu)

Uudet:
- responsiivinen-v263.css (kummankin näkymän CSS)
- kayntikohteet-v263.js (säilyttää vanhat kohdelähteet, lisää maakuntasuodatuksen)

Älä poista muita vanhoja tiedostoja, erityisesti
suomi-kunnat-v253.js, kayntikohteet-data-v230.js, nearby-data-v218.js
ja navigation-v191.css. Niitä käytetään edelleen.

Huom: ZIP ei julkaise itse itseään GitHubiin. Sivustolla näkyvät muutokset
vasta tiedostojen siirtämisen ja GitHubin julkaisun jälkeen.
