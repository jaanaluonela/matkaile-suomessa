MATKAILE SUOMESSA - v334 TIETOKONESIVUT YHTEEN PALSTAAN

TÄMÄ ON PIENI PÄIVITYSPAKETTI, EI KOKO SIVUSTO.
Se on suunniteltu nykyisten tiedostojesi päälle. Se EI korvaa kuntatietoja,
maakuntia, matkamuistoja, suosikkeja tai hakutietoja.

MITÄ MUUTTUU TIETOKONEELLA (näytön leveys vähintään 900 pikseliä):
- Maakunnat: iso aito kuvaotsake, haku, kartta ja maakuntalista PERÄKKÄIN.
- Leirintäalueet: hakuehdot ylös, tulokset alle. Ei vasenta sivupalstaa.
- Kortit leveämmiksi ja helppolukuisemmiksi.
- Myös muut uudemmat kaksipalstaiset sisältöasettelut pinoutuvat.
- Etusivun sisältö hyödyntää tietokoneen leveyttä paremmin.
- Puhelinversio ei muutu (alle 900 px).

KÄYTTÖÖNOTTO GITHUBISSA:
1. Pura ZIP tietokoneella.
2. Siirrä tiedostot oman GitHub-repositorion JUUREEN niin, että polut pysyvät:
     tietokone-v334.css
     tyokalut/lisaa_tietokone_v334.py
     .github/workflows/tietokone-v334.yml
   LUE_ENSIN_v334.txt on ohje, sitä ei tarvitse siirtää GitHubiin.
3. Tee GitHubissa Commit changes päähaaraan (main/master).
4. Avaa GitHub -> Actions -> "Matkaile Suomessa - tietokoneulkoasu v334".
   Odota vihreää onnistumismerkkiä. Automaattinen työ lisää css-linkin
   olemassa olevien HTML-sivujen HEAD-osaan (ilman että sisältöjä korvataan).
5. Odota Pages-julkaisua ja tee selaimessa Ctrl+F5.

JOS ACTIONS EI AJA: GitHubissa Actions -> valitse uusi työ -> Run workflow.
Vaihtoehtoisesti paikallisella koneella projektin pääkansiossa:
     python tyokalut/lisaa_tietokone_v334.py
ja sitten vie muuttuneet .html-tiedostot GitHubiin.
