MATKAILE SUOMESSA - ALAVALIKKO KAIKILLE SIVUILLE v332

Ongelma: mm. Heinolan sivulla näkyy yhä Koti / Yöpyminen / Paikkakunnat.
Korjaus: neljä painiketta jokaisella HTML-sivulla:
Koti - Paikkakunnat - Pysähdy matkalla - Omat matkat.

TÄMÄ PAKETTI SISÄLTÄÄ VAIN YHDEN GITHUBIIN VIETÄVÄN TIEDOSTON:
.github/workflows/korjaa-alavalikko-v332.yml

Asennus:
1. Pura ZIP-tiedosto ensin tietokoneelle.
2. Avaa GitHubissa Matkaile Suomen repositorio.
3. Avaa kansio .github ja sen alta workflows.
4. Valitse Add file -> Upload files ja lataa korjaa-alavalikko-v332.yml.
   Jos workflows-kansiota ei ole, luo se ensin. Säilytä polku täsmälleen.
5. Commit changes. Avaa Actions ja tarkista, että
   'Matkaile Suomessa - alavalikko joka sivulle v332' onnistuu.
6. Odota GitHub Pages -julkaisu ja lataa sivu uudestaan.

Workflow muuttaa GitHubissa automaattisesti olemassa olevia HTML-sivuja
sekä luo yhden yhteisen alavalikko-v332.css-tiedoston. Sivujen muu sisältö
pysyy ennallaan. Edes v331:n CSS/JS-tiedostojen ei tarvitse toimia.

Jos GitHub Actions antaa virheen 'Permission denied / 403':
GitHub -> Settings -> Actions -> General -> Workflow permissions:
'Read and write permissions', jonka jälkeen Actions -> Run workflow.

Tätä ZIP:iä ei pidä ladata GitHubiin pakattuna tiedostona.
Tästä keskustelusta ei voi suoraan muuttaa GitHub-verkkosivua.
