Päivitetty: 18.10.2026

Paketin 3 sivustotiedostoa ladataan GitHub-repositorion juureen.
ÄLÄ lataa ZIP-pakettia sellaisenaan GitHubiin, vaan pura se ensin.
ÄLÄ poista muita tiedostoja, hakemistoja tai vanhoja kuntasivuja.

1. Avaa GitHubissa matkaile-suomessa -repository.
2. Valitse Add file → Upload files.
3. Vedä nämä kolme tiedostoa lataukseen ja vahvista korvaaminen:
   - alavalikko-v304.css
   - alavalikko-v304.js
   - etusivu-laadukas-v352.css
4. Valitse Commit changes / Vahvista muutokset.
5. Odota GitHub Pagesin päivitystä; päivitä selaimessa Ctrl+F5 tai Ctrl+Shift+R.

Muutokset:
- Yhteinen yläpalkki, sivuston logo ja ensisijaiset linkit.
- Helppo mobiilivalikko ja neljän kuvakepainikkeen alavalikko.
- Samat värit, otsikot, perustietokortit, painikkeet ja kontrastit.
- Kunnan olemassa oleva vaakuna ja asukasluku nostetaan esiin koskematta lukuihin.
- Etusivun silta-kuvan tilalle asetetaan aito Päijänne-valokuva.
